# Changelog

## 1.7.0 — supplied source candidate, 2026-10-27
The supplied archive unifies the five published application versions at 1.7.0. Its upstream notes describe version-string changes and corrected CYD numeric version constants. This repository preparation preserves the selected firmware bytes and partition tables, organizes paths and adds documentation.
