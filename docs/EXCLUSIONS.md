# Exclusions from publication
- Original/rollback ZIPs and nested duplicate release tree: preserved locally, not recursively promoted into public source.
- Historical source branches, patches and prior validation claims: inventoried locally; not represented as current verified functionality.
- Original .git history, local state, SD recordings, upload histories and populated configuration: withheld to avoid secrets and location data.
- Existing binaries/full SD images: withheld as unverified and potentially credential-bearing.
- Absolute local filesystem inventory and raw compiler logs: retained only in private review/staging because they contain personal paths.
- Historical flashers, map maker, CAD assets and images: withheld pending dependency, privacy and licensing review.
- Hardware photographs/screenshots: none verified for redistribution in this candidate.

See the security scan report for scanned paths/categories and review limitations. These exclusions do not delete or alter originals.
