# Contributing
Explain the board, hardware revision, ESP32 core and library versions, reproduction steps, and expected behavior. Remove credentials, MAC/location recordings and personal paths from logs.

Keep firmware changes focused. Do not merge protocol or wiring changes across device families without evidence. Compile affected variants; report hardware tests separately. For scan changes exercise GPS loss/recovery, run/pause authorization, ESP-NOW join/rejoin, upload pause/resume, CSV archive failures and SD recovery on real hardware.

Licensing is pending owner approval and third-party provenance review. Do not submit code you lack permission to distribute. Do not attach unverified binaries as stable releases.
